**Consigna: Lista de Tareas con Vue.js**

Crea un archivo HTML utilizando Vue.js (Options API) que cumpla con los siguientes puntos:

1. **Agregar tareas:** Un campo de texto (`input`) donde el usuario escriba una tarea y se agregue a la lista al presionar la tecla Enter.
2. **Mostrar la lista:** Un `div` que renderice todas las tareas que se vayan ingresando.
3. **Marcar como completada:** Al hacer clic sobre una tarea, esta debe cambiar visualmente (por ejemplo, tachándose) para indicar que está completada. Si se hace clic de nuevo, vuelve a estar pendiente.
4. **Contadores:** Muestra en pantalla la cantidad exacta de tareas completadas y la cantidad de tareas faltantes, calculando esto de forma automática.
